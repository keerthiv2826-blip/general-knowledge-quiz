# 🧠 General Knowledge Quiz

A web-based General Knowledge Quiz application developed using HTML, CSS, and JavaScript.

## 🚀 Features

- 🟢 Easy, Medium and Hard difficulty levels
- ❓ 3 questions per difficulty level
- 🔀 Random question order
- ⏱️ 10-second timer
- ⭐ Score system
- 🏆 High score using Local Storage
- 💡 Hint system
- ❤️ 3 lives
- 📊 Result analysis
- 📱 Responsive design
- 🔄 Play Again option
- 🎯 Change Difficulty option

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
